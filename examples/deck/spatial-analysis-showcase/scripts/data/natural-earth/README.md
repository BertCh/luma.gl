# natural-earth
Natural Earth world reference geometry. Public domain; credit "Made with Natural Earth".

- Source: https://github.com/nvkelso/natural-earth-vector (`geojson/ne_110m_land`, `ne_110m_coastline`, `ne_110m_admin_0_countries`, `ne_110m_admin_0_boundary_lines_land`, `ne_110m_lakes`, `ne_10m_land`, `ne_10m_coastline`, `ne_10m_admin_0_boundary_lines_land`, `ne_10m_lakes`, `ne_10m_rivers_lake_centerlines`), downloaded 2026-10-07 from https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/. Terms: https://www.naturalearthdata.com/about/terms-of-use/.
- Processing (`python -I build.py path/to/raw-dir`): 110m files keep their geometry (4 decimals), properties reduced (countries keep `NAME`, `ISO_A3`, `CONTINENT`, `REGION_UN`; `-99` ISO codes replaced by `ADM0_A3`); 10m files clipped to the Netherlands region `[2.5, 50.6, 7.5, 53.8]` (5 decimals). Natural Earth's own antimeridian splits are kept.
- Output (717 KB, 23 files): `ne_110m_land`, `ne_110m_coastline`, `ne_110m_admin_0_countries`, `ne_110m_admin_0_boundary_lines`, `ne_110m_lakes`, `ne_10m_land_nl`, `ne_10m_coastline_nl`, `ne_10m_boundary_lines_nl`, `ne_10m_lakes_nl`, `ne_10m_rivers_nl` (all `.geojson`; `manifest.properties.files` lists them). Binary columns: countries unprefixed (`vertices`, `ringOffsets`, `polygonRingOffsets`, `partFeature`, `name`, `iso3`, `continent`, `regionUn`) and land as `landVertices`, `landRingOffsets`, `landPolygonRingOffsets`, `landPartFeature`.
