# us-airline-flows

Source: BTS On-Time Reporting Carrier On-Time Performance, July 2023 (public domain), https://www.transtats.bts.gov/PREZIP/ . Airport coordinates from OpenFlights airports.dat (ODbL; run scripts/data/openflights/build.py first or have its raw cache present).
Weights are flights, not passengers (T-100 passenger tables need an interactive download).
