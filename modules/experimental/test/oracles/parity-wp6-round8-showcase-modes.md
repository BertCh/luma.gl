## Reference conventions that matter

- R is now available through WebR, installed under the supplied reference venv while holding `venv.lock`. The bridge loads actual `spatstat.explore` 3.8-3 and `spatstat.geom` in its isolated virtual filesystem. [WebR Node setup](https://docs.r-wasm.org/webr/latest/downloading.html) and [package installation](https://docs.r-wasm.org/webr/latest/packages.html). This is generator-only tooling.
- Donnelly's coefficient convention is adapted explicitly: recover spatstat's expectation from its ratio, then subtract `0.0002 * perimeter / n**1.5` to change 0.0412 to the API's documented 0.041. Standard errors and tails use the cited definition and independent SciPy functions.
- Hanisch/Chiu–Stoyan uses a labelled composite because spatstat Gest weights radius bins, while this API weights individual observations and has a cap, truncated-search denominator, and interpolated polygon reference-lattice erosion. Comparing straight Gest would compare different estimators. NumPy weighted empirical CDFs, Shapely geometry and SciPy distances independently compose the documented estimator. Geometric approximation bias versus the continuum estimator is not certified away.
- Polygon samples exactly on an edge use the public downward/leftward symbolic ownership, not closed-set `covers`: for these axis-aligned windows, Shapely `contains` on one f64 predecessor in each coordinate independently realizes that rule. Boundary distances still use the original samples. This matters for the 94×94 grid at hole edges.
- New point radii are selected by **geometry-only** screening before any GPU execution. All 20/30/60 radius grids share a dyadic finest step; exact ties are retained and non-exact distances within eight f32 epsilons of a radius are excluded by changing the input radius, not comparison tolerance. Chosen maximum = 15.02197265625, attempt 6.
- No library source changed in round 8. GPU evidence is still required to confirm numerical parity and the round-7 moment repair.
